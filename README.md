# Telco Customer Churn Prediction

## Project Overview
This project aims to predict whether a telecom customer is likely to leave the company (Churn) using Machine Learning.

Customer churn prediction helps telecom companies identify customers who may leave their services and take preventive actions to improve customer retention.

## Problem Statement
The objective is to build a Machine Learning classification model that predicts customer churn based on customer information, service usage, and account details.

## Dataset
- Dataset: Telco Customer Churn
- Total Records: 7,043
- Total Original Features: 21
- Target Variable: `Churn`
- Classes: `Yes` and `No`

## Evaluation Metrics
- Accuracy
- Precision

- F1-Score
- Confusion Matrix
- ROC-AUC
- Precision-Recall AUC

## Project Objective
The main focus is to identify customers who are likely to churn. Therefore, Recall is an important evaluation metric because missing a customer who is likely to leave can result in business losses.
